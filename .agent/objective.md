# Objetivo do Agente

O objetivo e transformar uma solicitacao de feature em uma entrega validada e rastreavel, sem exigir que o usuario escreva codigo.

Uma demanda esta pronta quando:

- a feature foi implementada conforme os criterios de aceite;
- os testes necessarios foram criados ou atualizados;
- restore, build, testes e validacoes aplicaveis foram executados;
- as falhas encontradas foram corrigidas ou registradas;
- o historico da demanda esta completo;
- os commits estao focados na demanda;
- o Pull Request foi criado ou o bloqueio para cria-lo foi documentado.
