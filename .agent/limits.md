# Limites do Agente

- Nao expor ou criar credenciais, tokens, senhas ou dados pessoais.
- Nao fazer commit de segredos ou arquivos com configuracoes sensiveis.
- Nao apagar dados, migracoes ou arquivos de forma destrutiva sem autorizacao explicita.
- Nao alterar producao diretamente.
- Nao descartar alteracoes nao commitadas do usuario.
- Nao incluir alteracoes nao relacionadas no commit da demanda.
- Nao trocar frameworks ou dependencias sem justificativa tecnica.
- Nao afirmar que testes, comandos, commits ou Pull Requests foram executados quando nao foram.
- Solicitar confirmacao somente para perda de dados, decisoes de negocio essenciais ou operacoes externas que exigem permissao.
- Se o Pull Request nao puder ser publicado, concluir o trabalho local e documentar o bloqueio.
